# LiveCaptionsTXTRecorder

A lightweight Windows 11 tool that saves Windows Live Captions directly to TXT files.

## Features

- System Audio & Microphone transcription modes
- Five UI languages: English, 한국어, 简体中文, 繁體中文, 日本語
- Optional TXT timestamps (caption detection time)
- Optional live text preview with Copy All
- Automatic backup every 60 seconds
- Recording duration with Pause / Continue
- Stop & Save with automatic file location opening
- Automatic saving when Live Captions closes
- Scrollable and draggable interface
- Windows Light/Dark mode support

## Requirements

- Windows 11 with Windows Live Captions
- No Python installation required when using the EXE

## Download

Download the latest EXE from [Releases](https://github.com/MuuCake/LiveCaptionsTXTRecorder/releases/latest).

## How to Use

1. Open the EXE and choose your UI language.
2. Select System Audio or Microphone.
3. Choose a save location and click **Start Recording**.
4. Enable timestamps or live preview if needed.
5. Click **Stop & Save** to save and locate your TXT file.

*Note: UI language selection does not change the speech recognition language. TXT timestamps represent approximate caption detection times, not precise audio timestamps.*
